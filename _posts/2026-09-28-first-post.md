# 我的第一篇博客：个人网站搭建之路


## 开始 / Introduction

这是我的第一篇博客。

创建这个个人网站的想法来源于希望能够记录自己的学习过程、项目经历以及成长轨迹。随着大学学习的深入，我逐渐意识到，仅仅完成课程学习是不够的，更重要的是建立属于自己的知识体系，并留下不断积累的痕迹。

因此，我决定搭建一个属于自己的个人主页。


## 为什么建立个人网站 / Why I Built This Website

相比于社交平台，个人网站拥有更高的自由度。

这里可以记录：

- 学习笔记
- 编程项目
- 数学理解
- 科研探索
- 个人思考

它不仅是一个展示自己的窗口，也是一个长期积累知识的地方。

我希望几年之后回顾这个网站时，能够看到自己从一个初学者逐渐成长的过程。


## 搭建过程中的困难 / Challenges

建立这个网站并没有想象中简单。

最开始接触 GitHub Pages 和 Academic Pages 模板时，大量的文件结构和配置让我感到陌生。

其中遇到的问题包括：

### 1. 理解网站结构

Academic Pages 使用 Jekyll 框架搭建。

第一次看到：

- `_pages`
- `_posts`
- `_config.yml`
- `_data`

这些文件夹时，并不知道它们分别负责什么功能。

经过不断查阅资料和尝试，我逐渐理解：

- `_pages` 负责网页页面
- `_posts` 负责博客文章
- `_config.yml` 负责网站整体配置
- `_data` 负责导航等数据


### 2. 修改模板

原始模板主要面向科研人员，其中包含：

- Publications
- Talks
- Teaching

等页面。

但是对于本科阶段的学生来说，更重要的是：

- Projects
- Learning
- Blog

因此我重新设计了网站结构，使它更符合自己的需求。


### 3. 调试与更新

网站搭建过程中，经常遇到修改后没有立即生效的问题。

需要不断检查：

- 文件路径是否正确
- Markdown 格式是否正确
- GitHub Pages 是否成功部署

这些过程虽然繁琐，但是也让我逐渐熟悉了网站开发的基本流程。


## 我的收获 / What I Learned

通过这次搭建网站，我不仅学会了如何使用 GitHub Pages 和 Jekyll，也更加理解了：

> 一个好的工具，需要通过不断实践才能真正掌握。

遇到问题、搜索资料、尝试修改、解决错误，这个过程本身就是学习的一部分。


## 未来计划 / Future Plans

未来，我希望继续完善这个网站，并记录：

- 数学课程学习过程
- C语言与Python学习
- 算法练习
- 人工智能相关探索
- 个人项目经历

希望这个网站能够成为我大学几年学习道路上的一个长期记录。


## 结语 / Conclusion

个人网站的建立只是一个开始。

未来还有很多知识需要学习，也有很多问题需要探索。

希望几年后的自己，再次打开这个网站时，能够看到一路成长留下的痕迹。
